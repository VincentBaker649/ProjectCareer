Job Prep

What is it?

Software developers create the computer applications that allow users to do specific tasks and the underlying systems that run the devices or control networks.

In this job you will:

  1. Analyze user's needs and then design and develop software to meet those needs
  2. Recommend software upgrades for customer's existing programs and systems
  3. Design each piece of an application or system and plan how the pieces will work together
  4. Create a variety of models and diagrams showing programmers the software code needed for an application
  5. Ensure that a program continues to function normally through software maintenance and testing
  6. Document every aspect of an application or system as a reference for future maintenance and upgrades

Daily Tasks

  1. Monitor computer system performance to ensure proper operation.
  2. Analyze project data to determine specifications or requirements.
  3. Develop testing routines or procedures.
  4. Manage information technology projects or system activities.
  5. Coordinate software or hardware installation.
  6. Collaborate with others to determine design specifications or details.
  7. Modify software programs to improve performance.
  8. Communicate project information to others.
  9. Prepare data for analysis.
  10. Assess database performance.
  11. Apply mathematical principles or statistical approaches to solve problems in scientific or applied fields.
